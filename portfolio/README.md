# Anmol Malviya — Founder Portfolio

A dark, editorial founder portfolio built with Next.js, CSS, Three.js via React Three Fiber, GSAP, and Lucide icons.

## Run locally

```bash
cd portfolio
npm install
npm run dev
```

Open http://localhost:3000.

## Customize before launch

- Replace the placeholder contact email `hello@anmolmalviya.com` with your preferred public email.
- Replace the generic LinkedIn URL with your actual profile URL.
- Confirm project descriptions and technology lists against each repository.
- Add a custom domain in Vercel when ready.

## Stack

- Next.js 14 / React 18 / TypeScript
- Three.js + React Three Fiber + Drei
- GSAP
- Custom responsive CSS
